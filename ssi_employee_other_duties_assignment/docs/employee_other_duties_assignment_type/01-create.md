# Create Employee Other Duties Assignment Type

> **Module:** ssi_employee_other_duties_assignment\
> **Model:** `employee_other_duties_assignment_type`\
> **Menu:** Human Resource > Configuration > Other Duties Assignment > Types\
> **Actor:** user in group `Human Resource - Configurator / Employee Other Duties Assignment Type`

## Pre-Condition

- None.

## Flow

1. Open the **Human Resource > Configuration > Other Duties Assignment > Types** menu.
2. Click the **New** button. **(14.0: "Create")**
3. Fill in the required fields:
   - **Name** *(required)*: Enter the type name.
   - **Code** *(required)*: Enter a unique code for this type, or fill with **/**.
4. Click **Save**.

## Post-Condition

- A new Employee Other Duties Assignment Type record is created and available for
  selection as **Type** on an Employee Other Duties Assignment record.
